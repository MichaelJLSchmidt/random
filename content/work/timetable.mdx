## The problem

The region printed one timetable, put a PDF of it online and painted a third version at stops. Each had been edited separately for years and none of them agreed.

## What we changed

We started from the question people actually ask at a stop: when is the next bus, and will it get me there? Every format now answers that first, then shows the full table for those who need it.

- A single source table that generates print, web and stop displays
- Times set in tabular figures with clear rules between peak and off-peak
- Route colours replaced by numbers and patterns so the timetable works in black and white

## How it was built

The data model came first. A small build tool turns the operator's export into accessible HTML tables, print-ready PDFs and display layouts, so a change is made once.

## Outcome

Support calls about wrong times fell sharply after launch, and the operator now publishes changes the same day instead of waiting for the next print run.
